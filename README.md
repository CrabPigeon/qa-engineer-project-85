Codebattle - это проект от команды онлайн-школы программирования Hexlet. Codebattle позволяет программистам использовать их любимые языки программирования в битвах один на один.

Тестовая документация проекта включает:
- requirements.yml
- test-cases.yml
- testing-report.yml
- issues.yml
- reopened_issues.yml
